# cautious-structures-spoon-in-cplusplus
- Several Algorithms for use in Structures - there are many algorithms that I have lost because of not saving them in a dedicated folder or Repository for fast access. That is why I am creating algorithms for structures- useful algorithms which can be used in other programs
**Structures are defined in the following way:**
  ```
  // Struct Keyword, Tag of the structure, Define variables in the structure, known as members
  struct Test
  {
    int a;
    string b;
    string c;
  }

  int main()
  {
    Test t;
    t.a = 6;
    t.b = "hello\n";
    t.c = "Goodbye\n";

    cout << t.a << " " << t.b << " " << t.c << endl;
  ```
